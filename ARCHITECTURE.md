# Architecture

`MainActivity` owns native English UI, document selection and settings. No cookie-test/preflight gate is required. JSON parsing, identity normalization, storage, network/browser operations, codec and queue coordination are separate classes.

`QueueEngine` is the only result/SAF writer. An in-flight set and bounded executor prevent duplicate assignments and duplicate commits. SQLite stores normalized account order, queue phases, attempts, output image metadata and folder-scope state. Re-importing the same JSON is a no-op; changed lists keep state for accounts that remain. Interrupted WebView claims return to pending on recovery. Start Missing rechecks saved output URIs so deleted files can be fetched again; Retry Failed includes skipped rows. Scheduled jobs process one bounded profile; user-started foreground runs may overlap pages within a resource cap.

A global profile launch deadline enforces random minimum/maximum delays independently of the concurrency ceiling. `ConcurrencyPolicy` starts conservatively from free RAM, heap class and low-RAM status; memory trim/renderer death halves the ceiling. Existing assignments drain before a lower cap allows new dispatch. The provider trims idle pages. App PSS, pool creation/reuse and limit changes use bounded, account-redacted diagnostics.

`WebViewProfileProvider` holds a single browser cookie lease. CookieManager initialization occurs once per provider session, not once per account. All WebView operations are main-looper confined. Main-thread idle-page and live-page collections bound creation. Every assignment has its own result latch, token, expected username and callbacks. A completed page is reset to about:blank with scripts disabled before reuse; late callbacks see the completed assignment and cannot supply the next account's result. A failed reset destroys the page. Renderer loss destroys affected instances and reduces future capacity. Closing the session destroys the pool, purges browser storage/cookies and releases its exclusive lease only after the cookie callback.

Navigation, resource allowlists, loaded-image verification and identity matching remain required. Native CDN transfers use separate cancellable downloaders with a maximum of two concurrent transfers and no cookies. Page subresources are browser-managed, with an independent 600-request budget per assignment. Pool size is not a promise of an equal number of HTTP requests.

`FailurePolicy` distinguishes account-local unavailable/missing/timeout errors (Skipped this run) from global cookie/challenge/rate/access restrictions (pause), and from image failures (Failed, continue). Storage faults stop. No deletion inference is made from an unavailable page. There is no consecutive account-failure stop threshold.

`ThumbnailCodec` accepts valid 128 or 256 WebP outputs and generates new 256 WebP at quality 78. `OutputFolder` indexes SAF image URIs once per selected folder scope, checks each referenced file as it is reused, and offers an explicit full index verification. `OutputIndexObserver` watches the selected SAF tree, invalidates changed indexed URIs, and requests a full verification when a provider reports an unindexed change. It stages, reads back and renames files before success. Recovery removes interrupted partial files on the next targeted check. Output contains only account files and transient transaction files; queue/log/session data is private. The UI and diagnostics report valid indexed images outside the supported 128/256 square sizes.

`DownloadNotification` derives progress and terminal states from SQLite counts, reports active worker limits, cooldown details and Retry-After when available, and rate-limits notification updates. `WorkScheduler` retains eligible rate-limit cooldowns and plans continuation inside the saved working-hours window when Background Processing is enabled.

`PhotoViewer` loads a local thumbnail first, then reuses the same browser provider in HD mode when the queue session is free. It accepts only explicitly discovered account-bound HD URLs/srcset sources; CDN paths are not guessed or rewritten. HD bytes/bitmap live only in memory, bounded decoding can sample very large sources, and the UI reports source and sampled dimensions separately. Closing clears the bitmap and cancels work. It has no gallery, saved-HD archive or profile search feature.
